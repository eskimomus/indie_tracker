# Indie Game Tracker

Сервис собирает трейлеры/анонсы инди-игр с YouTube и новые релизы из Steam,
достаёт из них контакты разработчика (Discord, Steam, X, Instagram, сайт)
и показывает единым списком с фильтром по площадке и порогу популярности
(просмотры / отзывы).

Reddit и X (Twitter) в этой версии не подключены. Reddit убрали из-за
проблем с прохождением reCAPTCHA при создании приложения — при желании
модуль легко восстановить (структура осталась в git-истории / можно
написать заново по образцу `youtube.py`, используя библиотеку `praw`).
X не подключён, т.к. официальный API платный (от ~$200/мес).

## Структура

```
backend/
  main.py                 — FastAPI-приложение и REST API
  models.py                — таблицы Game и Finding (SQLModel)
  database.py               — подключение к БД
  scheduler.py               — фоновый запуск сбора данных каждые 6 часов
  ingestion/
    youtube.py                — поиск трейлеров/анонсов на YouTube
    steam.py                    — новые релизы в Steam
    contact_extractor.py         — регэкспы для discord/steam/x/instagram/сайта
    game_matcher.py                — fuzzy-сопоставление находок с играми
frontend/
  index.html                — дашборд со списком и фильтрами
```

## Запуск

1. Установите зависимости:
   ```
   cd backend
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и заполните ключ:
   - `YOUTUBE_API_KEY` — Google Cloud Console → включить "YouTube Data API v3" → создать API-ключ.
     Бесплатная квота 10 000 unit/день, один поиск = 100 unit.
   - Steam-модуль ключа не требует (используется публичный storefront API).

3. Запустите сервер:
   ```
   uvicorn main:app --reload --port 8000
   ```

4. Откройте http://localhost:8000 — увидите дашборд.
   Он сам обратится к `/api/games`.

5. Сбор данных запускается автоматически каждые 6 часов (см. `scheduler.py`),
   либо вручную — кнопкой "Собрать данные сейчас" в дашборде
   (дергает `POST /api/ingest/run-now`).

## Что стоит доработать перед продакшеном

- **Rate limiting / уважение к API квотам.** Особенно YouTube (10k unit/день)
  и парсинг Steam-страниц (не долбить чаще раза в секунду — уже заложена
  задержка в `steam.py`, но при масштабировании стоит добавить очередь).
- **Postgres вместо SQLite** — просто смените `DATABASE_URL` в `.env`,
  код менять не нужно (SQLModel одинаково работает с обоими).
- **Дедупликация игр** — сейчас fuzzy-matching по названию (`rapidfuzz`,
  порог 85%). На практике возможны ложные объединения/разделения —
  стоит завести админ-эндпоинт для ручного слияния/разъединения записей.
- **Очистка названий из YouTube** — `youtube.py` берёт заголовок видео как
  есть; полезно регэкспом отрезать "| Official Trailer", "- Announcement"
  и т.п., чтобы матчинг работал лучше.
- **Reddit** — если решите вернуть, модуль строится по аналогии с `youtube.py`,
  через библиотеку `praw`; единственная сложность — прохождение reCAPTCHA
  при создании Reddit-приложения на reddit.com/prefs/apps.
- **X/Twitter** — при готовности платить, модуль добавляется через
  `tweepy` и official API v2.
